# Сервис управления документами (DocFlow)

## Назначение
Сервис предназначен для централизованного хранения, классификации, контроля версий и отслеживания статуса обработки электронных документов внутри организации или команды. Проект решает проблему потери актуальных редакций файлов и упрощает документооборот.

## Целевая аудитория
- Сотрудники компаний и отделов (бухгалтерия, отдел кадров, юридический отдел);
- Руководители проектов и подразделений, согласующие документацию;
- Фрилансеры и небольшие команды, работающие с договорами, отчетами и актами.

## Предметная область
Системы электронного документооборота (СЭД). Область включает в себя жизненный цикл документа: создание черновика, распределение по категориям, загрузку новых версий, согласование, подписание и архивацию.

## Основные сущности
- **Пользователь** — автор или редактор документа, обладающий определенными правами доступа.
- **Документ** — основной информационный объект (название, дата создания, текущий статус).
- **Категория** — раздел для тематической классификации документов (например: «Договоры», «Приказы», «Отчеты»).
- **Версия** — конкретная редакция документа с номером версии, датой изменения и статусом согласования.

## Основные функции
- Создание и загрузка новых документов;
- Классификация документов по категориям;
- Фиксация новых версий при редактировании файлов;
- Проверка документов на соответствие требованиям (размер файла, подпись);
- Контроль статуса документа (черновик, на согласовании, утвержден, в архиве).

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
